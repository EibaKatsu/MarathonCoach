# RaceNavi Note Editor Profile

## Overview

- note URL: `https://note.com/ebasan`
- 目的: RaceNavi / GateChecker にまつわる体験、気づき、開発背景を、技術紹介だけに寄せず読み物として伝える。

## Writer profile

- 富山の市民ランナー
- 本業や肩書きは前面に出さない
- 登山が入口で、山を走るランナーへの憧れからトレイルを開始
- 第1回富山マラソン（2015年）に合わせてフルマラソンを開始し、以来毎年出場
- フル、ハーフ、トレイルなど年間10レース前後
- 月間走行距離は冬場50km、多くても150kmほど

## Performance context

- フル PB: `3:54:30`（長野マラソン）
- 普段は `4時間〜4時間半` が多い
- 直近の富山マラソンは `4:03:30`

## Why RaceNavi exists

- レース中に「今どこまで心拍を上げていいか」が分かりにくかった
- 心拍 165 超が続くと長続きしない感覚があった
- 魚津しんきろうマラソン（ハーフ）で、心拍 165 を超えない走りで当時 PB を出した
- ただし残り 2km で強いラストスパートができ、余力を残しすぎた感覚もあった
- 現在心拍は見えても「どこまで上げてよいか」の目安がなかった
- 普段はペースと心拍中心で、ゴール予測は頭の中で計算していた
- Garmin 画面で足りないのは「ゴール予測」だと感じていた

## Product background

- RaceNavi Core は `心拍CAP + 現在ペース + ゴール予測` を 1 画面で判断しやすくするためのプロダクト
- GateChecker は `1つのアプリ + Race Code` で大会とコースを切り替える別プロダクト
- note では仕様の列挙より、なぜその形にしたのか、どんな迷いから生まれたのかを優先する

## Writing style

- 体験談、開発ストーリー、レース戦略をバランスよく混ぜる
- 技術説明に寄せすぎず、ランナーとしての実感を主役にする
- 落ち着いた誠実さを保ちつつ、硬くしすぎない
- 失敗談や弱さは隠さず書く
- 売り込みは強くしすぎない

## Expected readers

- ペース配分が分からない人
- 基本は分かるが実戦で判断に迷う人
- Garmin 画面の情報量と判断のしやすさに関心があるランナー

## Landing

- Connect IQ ページやサイトへの導線は入れてよい
- 感想やフィードバックをもらえる着地は歓迎
- ただし宣伝だけで終わる記事にはしない
