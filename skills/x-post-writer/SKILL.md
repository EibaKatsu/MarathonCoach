# X Post Writer

Race Navi の X 投稿を、その場しのぎで書かずに「実際の履歴確認 -> 投稿リスク確認 -> 文案作成」の順で作る。

## Quick Flow

1. `references/racenavi-context.md` を読む。
2. `@racenavi_run` の実際の直近投稿を確認する。
3. 依頼内容と直近投稿を比較して、連投や重複のリスクを判断する。
4. 問題なければ次の投稿案を作る。微妙なら先に短く指摘して、より安全な案も添える。

## Live Check

- 直近 1〜3 件の投稿本文と投稿日時を、必ず先に確認する。
- 可能なら絶対日付で確認する。相対表現だけで済ませない。
- 取得できるなら、最新投稿のテーマ、CTA、ハッシュタグも見る。
- 履歴確認に失敗したら、そのことを短く伝えたうえで `references/racenavi-context.md` のキャッシュ情報を使う。
- 履歴が部分的にしか取れない場合は、完全に把握したふりをしない。
- `statuses_count` と、実際に本文まで確認できた投稿数がズレる場合は、履歴不足として扱う。
- 履歴不足のときは、新規の単独投稿を強く勧めない。必要なら `待つ / 既存投稿への返信 / 結果報告まで保留` を優先する。

### Lookup Hints

- X のプロフィール HTML だけでは投稿本文が取れないことがある。
- 必要なら公開プロフィール情報と公開 GraphQL を使って確認する。
- 少なくとも `UserByScreenName` でプロフィールと `pinned_tweet_ids_str` は確認できる。
- `UserTweets` が `profileBestHighlights` のみ返す場合は、履歴取得が不完全だと判断する。
- その場合も、直近確認不足を明示したうえで文案作成は続けてよい。
- ただし、その場合の文案は保守的にする。直前投稿と同テーマの新規投稿は避ける。

## Risk Check

- 最新投稿から 6 時間以内で、かつ新情報が薄いなら、まず「少し間隔を空けた方が自然」と伝える。
- 24 時間以内で、同じ CTA、同じ価値訴求、同じハッシュタグ構成が続くなら、重複っぽさを指摘する。
- 直近 2 投稿がどちらも募集・宣伝寄りで、今回も募集だけなら、改善ログや実走報告への切り替えを勧める。
- ユーザーが連投を望んでも、X 上で不自然になりそうなら止める。止めたうえで、代替案を出す。
- 会話の直前ターンで、すでに同趣旨の投稿案を出している場合も `最近の履歴` とみなして重複判定に含める。
- 次のような使い方は避ける:
  - 新情報なしの連続募集
  - URL を複数入れる
  - ハッシュタグの付けすぎ
  - 実体験や検証がないのに大きな効果を断定する

## Writing Style

- 基本の立ち位置は `公式アカウント × 中の人あり`。
- `中の人より。` は使わない。
- ふだんの主語は `レースナビです。` が基本。不要なら主語なしでもよい。
- 会社広報っぽくしすぎない。ただし個人日記にも寄せすぎない。
- 価値訴求は `レース中の迷いを減らす` `見やすさ` `通知タイミング` `補給サポート` を軸にする。
- 機能羅列より、実走・検証・改善の具体を優先する。
- 日本語で作る。ユーザーが別言語を求めたときだけ変える。
- ハッシュタグは通常 0〜2 個、多くても 3 個まで。

## Output

- まず `投稿可 / 注意 / 今は非推奨` のどれかを 1 行で伝える。
- 次に推奨案を 1 本出す。
- 必要なら代替案を 1〜2 本まで添える。
- 注意や非推奨のときは、理由を 1 文で添える。
- 履歴不足や重複疑いがあるときは、`新規投稿案` より `返信案` や `翌日の結果報告案` を優先する。
- ユーザーが単に「X投稿文を作って」と言った場合でも、この順番で進める。

## Repo Context

- まず `references/racenavi-context.md` を読む。
- 直接投稿の実装や調査をするときは `references/x-direct-posting-research.md` を読む。
- 追加確認が必要なときだけ以下を読む:
  - `PRODUCT.md`
  - `TASKS.md`
  - `site/racenavi/README.md`
- 質問は最小限にする。イベントや目的が自明なら、確認より先に文案を出す。

## When To Push Back

- 直前投稿の直後で、明確な新情報がない。
- 同じ募集文や同じ CTA を繰り返そうとしている。
- X に不向きな長文、説明過多、宣伝感の強すぎる文になっている。
- その場合は黙って従わず、短く理由を言ってからより安全な案を出す。
