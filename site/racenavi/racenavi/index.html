RaceNavi

心拍とペースで、レース中の判断を減らす。

RaceNaviは、フルマラソン本番で心拍・ペース・目標との差・到達予測を1画面で確認するGarmin向けデータフィールドです。

数字を増やすためではなく、走りながら判断しやすくするために作っています。

レース中に見たいこと

  • 序盤で心拍を上げすぎていないか
  • 今のペースで目標タイムに届きそうか
  • 目標に対して貯金か、借金か
  • このまま行くとゴール予測はどれくらいか
  • 後半まで押せる状態か

表示する情報

  • 現在の心拍
  • CAP心拍
  • 現在のペース
  • 目標との差
  • 到達予測
  • 距離
  • 経過時間
Screen

画面イメージ

  • CAP HR: その時点での心拍上限目安です。
  • HR: 現在の心拍を確認します。
  • Pace: 現在の走行ペースです。
  • Prediction: このまま進んだ場合の到達予測です。
  • Difference from goal: 目標に対して貯金か借金かを見ます。
  • Distance: 経過距離です。
  • Time: 経過時間です。

CAP心拍について

CAP心拍は、その時点で許容する心拍上限の目安です。医療的な心拍管理ではなく、レース中に突っ込みすぎを避けるための参考値として扱います。

注意事項

  • Garmin公式アプリではありません。
  • 医療的助言ではありません。
  • 体調、暑さ、コース条件によって適切な判断は変わります。
  • 最終判断はランナー本人が行ってください。
Setup

使用前の設定

インストール後、使用前に事前設定が必要です。

  • Race Distance: Full Marathon / Half Marathon / 10Km から選択します。
  • Target Time Hour / Minutes: 目標タイムを時分で設定します。
  • LTHR: 心拍閾値の心拍数です。設定すると目安の精度を合わせやすくなります。
  • LTHRを設定しない場合は、Garmin側の心拍ゾーン設定を使います。
  • Custom Code: カスタム設定ページで作成したコードを入力すると個別設定を反映できます。

LTHR の考え方は Garmin の Lactate Threshold 解説 を参照してください。 心拍ゾーンについては Garmin の Heart Rate Zones 解説 も確認できます。
