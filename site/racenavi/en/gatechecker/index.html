Cutoff Guide

See how far and how long to the next cutoff.

Even if you looked at the cutoff table before the race, the details are easy to lose once you are moving. Cutoff Guide is the app I am building to keep the remaining distance and remaining time to the next cutoff on Garmin.

Aid information can also be shown when needed, but the main job is cutoff awareness. One app works with many races through Race Codes.

What it lets you see mid-race

  • Where the next cutoff is
  • How far to the next cutoff
  • How much time is left before that cutoff
  • What time that cutoff is set for
  • How far to the next aid station if you need it

One app, switched by Race Code

This is not a separate app for every race. You use one app, find the Race Code for your race here, put it into Garmin Connect, and sync your watch.

  • Install Cutoff Guide from Connect IQ
  • Find your Race Code on this website
  • Enter the Race Code in Garmin Connect app settings
  • Sync your watch
  • Use the watch to see the next cutoff during the race
Screen fields
  • Row 1: Shows where the next cutoff is and what time it closes.
  • Row 2: Shows how far and how long to that cutoff.
  • Row 3: Can show the next aid distance when needed.
