# step_plan

## 段階開発方針
- 一気に実装しない
- `1機能 + シミュレーター確認 + 1コミット` 単位で進める
- 問題が出たら次STEPへ進まず、そのSTEP内で修正・再確認する

## STEP一覧
1. 土台作成（Data Field最小構成、1行表示）
2. 設定2項目（レース距離/目標タイム）
3. 画面レイアウト枠（HR/CAP/PACE/DIST/TIME）
4. ペース計算（10秒平均、`--:--`フォールバック）
5. ACTION判定（ちょい上げ/そのまま/ちょい落とし）
6. 心拍CAP上限 + HR超過継続判定
7. 坂判定 + MessageInGarmin風メッセージ選択
8. 多言語対応（ja/en）
9. `LTHR` プロパティ上書き
10. カスタムコード `S1〜S5` 直指定
11. source 識別と診断ログ整理
12. 最終調整（視認性/軽量化/安定性）
