# simulator_checklist

通常 QA 全体の観点は `docs/dev/qa_checklist.md` を参照し、本ファイルではシミュレーターで先に潰せる項目に絞って確認する。

## シミュレーション確認観点（STEP13時点）
1. タイマー基準は `Data Field Timer Controls` の `Start/Pause/Lap` を使う
2. FUELが `35:00` から減る / Pause中停止 / Lapで `35:00` リセット
3. Lap連打時、20秒以内はリセットされない
4. 通常時カードは `小ラベル + メインメッセージ` の2段表示になる
5. 残り2分以内は `補給準備` ラベル + `fuelPrep` 文言へ切り替わる
6. 期限超過後は `補給NOW` ラベル + `fuelNow` 文言が最優先で出る
7. 左上が `現在心拍 + CAP` 表示になり、取得不可時は `--` / `CAP --` へ安全側にフォールバックする
8. HR超過が継続秒数で遷移し、回復5秒継続で解除
9. ゾーン取得不可時はHR超過カードに遷移しない
10. `UP / FL / DN` の坂判定が中央カードの文言選択に反映される
11. `fr255 / fr57042mm / fr57047mm` でWatchdogクラッシュなし
12. `ja/en` 多言語表示と英語改行を確認
13. 独自距離通知カードが出ない
14. DRIFT固定表示が出ない
