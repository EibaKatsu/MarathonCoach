# logic_fuel

## 補給間隔
- 通常版（距離別固定）
  - フル（上記以外）: 35分ごとに通知
  - ハーフ（`20.8-21.4km`）: 35分通知を1回のみ
  - 10K（`9.5-10.5km`）: 通知なし
  - 5K（`4.5-5.5km`）: 通知なし
- カスタムモード: 30〜40分レンジで個別調整

## LAP操作による補給リセット
- LAP押下時点を補給完了として `fuelDueTimeSec` を再計算
- 遅れて補給した場合も、押下時点から再カウント
- `lapDebounceSec`（例: 20秒）以内の連続リセットは無効

## カード/メーター整合
- 残り `> 2:00`
  - メーター: 通常
  - カード: 通常表示
- 残り `2:00〜0:01`
  - メーター: 注意
  - カード: `fuelState = PREP`
  - 1段目ラベル: `補給準備 / Fuel prep`
  - 2段目メッセージ: 選択カテゴリの `fuelPrep` から表示
- 残り `<= 0:00`
  - メーター: 警告
  - カード: `fuelState = NOW`
  - 1段目ラベル: `補給NOW / Fuel NOW`
  - 2段目メッセージ: 選択カテゴリの `fuelNow` から表示

メーター警告文言:
- 日本語: `補給now / 補給後LAP`
- 英語: `Fuel now / Press LAP`

## 表示優先順位（固定ルール）
1. FUEL NOW
2. FUEL PREP
3. EASE
4. HOLD / PUSH

## 補足
- 補給タイマー専用の表示枠は復活させない
- 補給ロジックそのものは維持し、表示上は `fuelState` として中央カードへ渡す
- `Lap` による補給リセットとデバウンス仕様は従来どおり維持する
