# ui

## 1. 現在の通常画面
- 通常画面はメッセージカード切り替えではなく、常時表示のダッシュボード1画面とする
- 画面の主役は中央の現在ペースと、上段の心拍 / 予測ブロックとする
- `small / medium / large` の3サイズクラスで同じ情報構成を保ち、フォントと余白だけを調整する

## 2. 画面構成
- 上段左: 心拍ブロック
  - 左上外周に心拍アーク
  - 上段1行目に `CAP心拍`
  - 上段2行目に `現在心拍`
- 上段右: 予測ブロック
  - 上段1行目に `予測ゴール時刻`
  - 上段2行目に `目標との差分（分単位のコンパクト表記）`
- 中央: 現在ペースブロック
  - 大きな現在ペース
  - 右下寄せの `/km`
  - その下にゴールランナーゲージ
- 下段左: 距離
- 下段右: 経過時間

## 3. 上段レイアウトの固定ルール
- 上段左の `CAP心拍` と上段右の `予測ゴール時刻` は、共通の2行グリッドに載せて縦位置を揃える
- 左右それぞれで独立に上下中央寄せしない
- 2行目のフォントが左右で異なっても、1行目の基準線が揃うことを優先する
- 2行目の数値フォントは可変だが、行高共有のために共通の下段行高を確保する

## 4. 心拍ブロック

### 4-1. 心拍アーク
- 心拍アークは左上外周のアーチとして描く
- 先にベースアークを描き、その上に現在心拍比率に応じた塗りアークを重ねる
- `CAP` 位置には短い白ティックを必ず表示する
- アーク上限は `arcMaxHr = min(capHr + 10, MaxHR)` を使う
- `MaxHR` が取れない場合は `capHr + 10` を仮上限にしてよい

### 4-2. 色
- `delta = currentHr - capHr`
- `delta <= -6`: 余裕色
- `-5 〜 -3`: 注意色
- `-2 〜 +1`: 警戒色
- `>= +2`: 危険色

### 4-3. 数値表示
- 上段1行目は `CAP心拍` の値だけを表示し、ラベルは出さない
- 上段2行目は `現在心拍` を number font で大きく表示する
- 心拍値は表示幅に収まる範囲で `FONT_NUMBER_HOT -> FONT_NUMBER_MEDIUM -> FONT_NUMBER_MILD` の順に縮小してよい
- 実際に採用した心拍2行目フォントは、右上の予測差フォント上限にも使う
- `CAP心拍` の数値表示は維持するが、色判定は ratio ではなく delta ベースとする

## 5. 予測ブロック

### 5-1. 1行目: 予測ゴール時刻
- 予測ゴール時刻は `CoachUtils.formatHourMin` 相当の `h:mm` / `hh:mm` 形式で表示する
- 予測不能時は `--:--` を表示する
- ラベルは出さない

### 5-2. 2行目: 目標との差分
- 差分表示はコンパクトな `+Nm` / `-Nm` / `0m` を基本とする
- 目標時刻が未設定、または予測不能時は `--m` を表示する
- レース距離を超過した後は差分欄に `Over` 相当の文言を表示する
- 日本語の詳細文言（例: `3分早い`, `2分遅れ`）は内部表示値として保持してよいが、通常ダッシュボードではコンパクト表記を優先する

### 5-3. フォントルール
- 差分は `符号 / 数字 / 単位` を分けて描く
- 数字だけ number font を使う
- `+/-` 記号と `m` 単位は通常フォントを使う
- 差分の数字フォントは、同フレームで確定した現在心拍の2行目フォントより大きくしてはならない
- large クラスでも、予測差の数字が心拍より強く見えないことを優先する
- ASCII数字を含まない差分文言を描く場合は number font を使わず、通常フォントにフォールバックする

### 5-4. 予測の表示条件
- 予測は以下を満たすときだけ有効にする
  - `raceDistanceKm` が有効
  - `targetTimeSec` が有効
  - 表示用ペースが有効
  - `elapsedSec` と `distanceKm` が有効
  - `distanceKm >= 0.05km`
- レース距離超過時は、予測時刻の代わりに `+x.xxkm` を表示する

## 6. 中央ペースブロック
- 中央の主役は現在ペースとする
- ペース値は number font を使い、`/km` は別フォントで右下寄せ気味に付ける
- 表示幅に収まらない場合は `FONT_NUMBER_HOT -> FONT_NUMBER_MEDIUM -> FONT_NUMBER_MILD` の順で縮小してよい
- 中央ペースの下にはゴールランナーゲージを置く

## 7. ゴールランナーゲージ
- ゲージは中央ペースの下に水平トラックとして表示する
- 旗は右端固定とする
- 自分ランナーと目標ランナーの相対位置で、目標に対して前か後ろかを直感的に示す
- 差分が `±60秒` 以内なら中央付近のデッドゾーンとして扱う
- 差分が `±10分` 以上なら端でクランプする
- 前にいるほど右、遅れているほど左に寄せる

## 8. 下段

### 8-1. 距離
- 下段左に距離を表示する
- 値と単位を分けて描き、単位は小さくする
- 例: `5.1 km`, `0.2 km`

### 8-2. 経過時間
- 下段右に経過時間を表示する
- 1時間未満は `mm:ss`
- 1時間以上は経過時間の通常フォーマットを使う
- large で幅が厳しいときは `FONT_LARGE` から `FONT_MEDIUM` へ落としてよい

## 9. ラベル削減ルール
- `HR`, `bpm`, `PACE`, `TIME`, `PRED`, `DELTA` などのラベルは通常画面に出さない
- 情報の意味は配置と単位で判別させる
- 数値の視認性をラベルより優先する

## 10. 現在の非採用UI
- 中央メッセージ常時表示は行わない
- コーチカード切り替え表示は通常画面では行わない
- 独自の距離節目カード表示は行わない
- DRIFT固定表示は行わない

## 11. 確認観点
- 上段1行目の `CAP心拍` と `予測ゴール時刻` が左右で揃って見えるか
- 予測差の数字が心拍より大きく見えていないか
- `+/-` と `m` が数字より控えめに見えるか
- 中央ペースが最も速く読めるか
- ゴールランナーゲージが pace 表示と下段表示に干渉していないか
- small / medium / large の各レイアウトで情報欠けや縦ずれがないか
