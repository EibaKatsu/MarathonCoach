# custom_mode

## 目的
通常版では扱わない個人差のうち、走り方強度と心拍上限バイアスを反映し、個別最適化する。

## 現在有効な調整項目
1. `phaseAggressiveness`（走り方強度 0..20）
2. `hrCapBiasBpm`（心拍上限バイアス -8..+8）
3. `driftSensitivity`（予約値 0..7）

- `hrCapBiasBpm` は `LTHR / HRR / MaxHR` のいずれかから算出した CAP HR に最後に加算する
- bias 適用後も、安全クリップを優先する

## 互換方針
- `custom_mode_code` のコード体系は後方互換のため旧スロットを保持してよい
- 旧来の補給関連スロットは decode / encode 上に残っていても、現行通常版では使用しない
- 仕様上の meaning を持つのは `phaseAggressiveness` と `hrCapBiasBpm` を優先する
- `driftSensitivity` はカスタムコード互換維持のため構造上は残すが、現行表示・判定では使用しない

## 設計方針
- ユーザーに見せる意味のある調整項目は最小限に保つ
- 内部の専門閾値は公開せず、抽象設定から展開する
- 通常版はシンプル維持、カスタムモードのみ個別最適化する

## カスタムコード方針
- 設定値は短いカスタムコードへ符号化して受け渡す
- コードに含める要素
  - バージョン情報
  - 設定本体
  - 誤入力検知用チェック値
- 目的は機密化ではなく、運用性 / 入力性 / 拡張性と後方互換の維持
