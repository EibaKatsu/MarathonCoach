# distance_cards

## 現在の扱い
- 2026-03-23 の中央カード再設計で、独自距離通知カードは廃止した
- Garmin 標準の距離通知を優先し、本アプリ側では 1km ごとの割り込み表示を行わない
- `HALF` / `FULL` を含む独自距離イベントの状態管理、キュー、繰り越し表示も対象外
- MessageInGarmin 由来の `DIST` カテゴリはデータ構造上は残してよいが、今回の表示対象にはしない

## 実装方針
- 中央カードの表示優先制御から距離イベントを外す
- 距離到達によるメッセージ切替は行わない
- 視認性と差分最小化を優先し、距離の文脈は下段 `DIST` 表示のみで扱う
