# core

## 通常版（Core）
目的: 信頼できる土台を提供し、レース中の判定バタつきを抑える。

### 含まれる機能
- コーチカード
  - 1段目: 判定ラベル（ちょい上げ/そのまま/ちょい落とし/補給準備/補給NOW）
  - 2段目: `坂 × ACTION` と `fuelState` から選ぶメインメッセージ
- 右下: いまのぺーす（10秒平均、`/km` 小表示）
- 距離/経過時間
- 心拍ZONE上限（Garmin心拍ゾーン基準、フェーズ別）
- 補給タイマー（LAPリセット、通常版は35分固定）
- 補給判定をメッセージ選択入力として利用
- `ja` / `en` の2言語対応
- 端末言語が `Japanese` のときだけ `ja`、それ以外は `en`

### 公開版で含めない機能
- FIT自動取り込み
- レース後の詳細分析やレポート出力
- 公開版UIでの高度な設定追加
  - 補給間隔
  - 初回補給タイミング
  - 心拍上限バイアス
- 後半レースモード
- 独自距離通知カード
- DRIFT判定 / DRIFT固定表示

個別最適化が必要な項目は公開版の範囲外とし、カスタムモードで扱う。

### モード方針
- 2モードのみ: 通常版 / カスタムモード
- 後半レースモードは実装しない

### 設定
- ユーザーが変更できる設定は2つのみ
  1. `raceDistanceKm`（km）
  2. `targetTimeSec`（HH:MM:SS）
- 補給は距離別の固定仕様（設定項目なし）
  - フル（上記以外）: 35分ごとに通知
  - ハーフ（`20.8-21.4km`）: 35分通知を1回のみ
  - 10K（`9.5-10.5km`）/5K（`4.5-5.5km`）: 通知なし
- 心拍ゾーンは Garmin 端末設定を取得する（設定項目なし）
- 端末ロケールが英語なら `en`、それ以外は `ja`
