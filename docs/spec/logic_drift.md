# logic_drift

## 現在の扱い
- 2026-03-23 の中央カード再設計で、DRIFT 判定と DRIFT 表示は廃止した
- 実戦で判定信頼性が不足したため、ACTION 判定の前提条件からも外した
- `水＋補給` の固定カード表示は行わない

## 実装方針
- コーチカードの状態選択は `fuelState` と `slope × action` のみで行う
- Cardiac Cost やドリフト基準確定に依存するゲートは現行通常版では使わない
- カスタムコード互換のため `driftSensitivity` の値域だけは構造上残すが、表示・判定では参照しない
