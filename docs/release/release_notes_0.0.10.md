# RELEASE Notes 0.0.10

## 追加
- `LTHR` を設定から直接指定できるようにし、デバイス依存に頼らず心拍CAPの基準を明示できるようにしました。
- `Custom Code` で `S1〜S5` の CAP bpm を直接指定できるようにしました。

## 変更
- 心拍CAPの決定優先順位を `custom code direct CAP -> property LTHR -> device LTHR -> HRR -> MaxHR` に整理しました。
- 設定画面や説明文の表記を `Custom Code` に統一し、`LTHR` と `Custom Code` に `(optional)` を付けました。

## 修正
- 明示した `LTHR` より明らかに低すぎる `MaxHR` があると CAP が不自然に低く潰れる問題を修正しました。
- カスタムコード生成スクリプトが旧 prefix を出してしまい、設定しても反映されない問題を修正しました。

## 削除
- 補給に関する仕様、ロジック、表示を削除しました。
- 旧来の方針ベースのカスタムモード指定を廃止し、`LTHR` 指定と `Custom Code` 直指定に整理しました。

## ランナーへの影響
- 心拍CAPを「自動計算に任せる」「LTHR を明示する」「各フェーズの最終CAPを直接決める」の3通りで、より意図どおりに使えるようになりました。
- カスタムコードを使う場合の挙動が明確になり、設定値どおりに CAP を反映しやすくなりました。
