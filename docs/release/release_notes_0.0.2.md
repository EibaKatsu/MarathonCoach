# RELEASE Notes 0.0.2

## 追加
- ラージ表示だけでなく、small / medium / large の全サイズで横長バナーレイアウトを使うように統一しました。

## 変更
- カード配色を見直し、`PUSH` 以外の通常カードが補給リングの青と競合しにくいように調整しました。
- 通常モードの補給間隔を、フルマラソンとハーフマラソンの両方で `35分` に統一しました。

## 修正
- medium の3行カードで文字がはみ出す問題に対して、行間と縦位置の扱いを見直しました。
- large / medium / small の横長バナー表示で、縁・内枠・文字のコントラストを見直し、視認性を改善しました。
- 心拍ブロックの表示順を調整し、`CAP` を上段、現在心拍を下段に変更しました。ハートアイコンも現在心拍行に揃えています。

## 既知の制限
- ストア申請に必要なサポート窓口 URL、プライバシーポリシー URL、利用規約 URL は引き続き未確定です。
- シミュレータでの確認は進めていますが、全対応機種の実機確認は継続中です。

## ランナーへの影響
- 画面サイズに関係なく、レース中のアドバイスと現在状態を同じ見方で把握しやすくなりました。
- 補給タイミングの理解が距離設定でぶれにくくなり、通常モードではフルもハーフも同じ `35分` ルールで使えます。
